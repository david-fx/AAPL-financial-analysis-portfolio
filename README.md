# Apple Inc. (AAPL) - 3-Statement Financial Model & Analysis

## 📌 Project Overview
This repository contains a comprehensive 3-statement financial model and valuation analysis for **Apple Inc. (AAPL)**. The project evaluates Apple's historical financial performance, key operational drivers, and future projections based on its latest financial statements.

*   **Prepared by:** David FX Winata
*   **Purpose:** Portfolio project demonstrating financial modeling and equity research skills.

## 📁 Repository Contents
This repository includes the following files:
1.  **`David_FW_AAPL_3Statement_Financial_Model.xlsx`** – The Excel model containing historical data, driver assumptions, and the integrated Income Statement, Balance Sheet, and Cash Flow Statement.
2.  **`David_FW_AAPL_3Statement_Financial_Model.pptx`** – The presentation slide deck summarizing the investment thesis and financial projections.
3.  **`David_FW_AAPL_3Statement_Financial_Model.pdf`** – The exported PDF version of the presentation for easy viewing.

## 🛠️ Methodology & Skills Demonstrated
*   **3-Statement Modeling:** Building an integrated financial model where Income Statement, Balance Sheet, and Cash Flow Statement are dynamically linked.
*   **Variance & Ratio Analysis:** Analyzing historical YoY growth, margins, and return ratios.
*   **Forecasting:** Projecting future revenues and expenses based on historical trends and industry assumptions.
*   **Data Visualization:** Creating a professional dashboard and presentation deck to communicate financial insights.
